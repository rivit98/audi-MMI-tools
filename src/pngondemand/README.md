# pngondemand

Renders a small text layout (rectangles, text, word-wrapped paragraphs) to
a PNG, on the car. `run.sh` uses it to draw each status screen right before
`showScreen` shows it (see [`sd/screens.sh`](../../sd/screens.sh)), so no
screens are pre-rendered.

```sh
pngondemand [-s] <layout|-> <out.png|->
pngondemand -h        # this usage + the layout commands
```

- `-` reads the layout from stdin / writes the PNG to stdout.
- `-s` (strict): text that does not fit is an error (exit status 2; the PNG
  is still written). Without it, it is only reported on stderr.
- Exit status: `0` ok, `1` usage, layout or I/O error (no PNG written),
  `2` text did not fit with `-s`.
- Errors name the layout line: `pngondemand: screen.layout:3: unknown colour "red"`.

The output is an 8-bit RGB PNG, like the unit's own
`rePartitioningNeeded.png`. A status screen is about 10–15 KB.

## Layout

One command per line, run top to bottom. Empty lines and lines starting
with `#` are ignored (only whole lines: a `#` later in a line is text).
Arguments are separated by spaces. **TEXT** is the rest of the line after
the single space that follows the last argument, so further spaces are part
of the text (use them to indent). Text is UTF-8.

| Command | |
|---|---|
| `size W H` | Canvas size, max 2048x2048. Default 800 480 (the MMI screen). Only before anything is drawn. |
| `colour NAME RRGGBB` | Name a colour (also spelled `color`). Redefining a name is allowed. |
| `bg COLOUR` | Fill the whole canvas. The canvas starts black. |
| `rect X Y W H COLOUR` | Filled rectangle, clipped to the canvas. |
| `text X Y FONT COLOUR TEXT` | Text with its top-left corner at X,Y. Not wrapped; clipped at the canvas edge. |
| `margin N` | Left and right margin of flow text. Default 24. |
| `at Y` | Move the flow cursor to Y. Default 20. |
| `gap N` | Move the flow cursor down N pixels. |
| `line FONT COLOUR [TEXT]` | Flow: one line at the left margin, then the cursor moves down by the font height. Cut at the right margin. Without TEXT it is an empty line. |
| `para FONT COLOUR TEXT` | Flow: TEXT word-wrapped between the margins, one `line` per wrapped line. A number and the word after it (`30 s`) are kept on one line. |
| `footer H FONT BG FG TEXT` | A bar of height H at the bottom in BG, with TEXT in FG at the margin, centred vertically. Flow lines stop above it, so put it before them. |

- **FONT**: `small` (8x16) or `big` (16x32): Terminus Bold, the same fonts
  as usb_tx_test (`sdk/fonts/`, SIL OFL). Characters the font lacks are
  drawn as `?`.
- **COLOUR**: `RRGGBB` hex (`#RRGGBB` also works) or a name from `colour`.
- **Flow text** (`line`, `para`) goes down from the `at` position. A line
  that would reach into the footer or below the canvas is not drawn and is
  counted as dropped; a line longer than the margins allow is cut. Both
  are reported on stderr (an error with `-s`).

## Example

```
# a status screen
colour accent 5AC8FA
colour text E8E8E8
bg 101820
rect 0 0 800 6 accent
footer 44 small 1C2836 text next app in 8 s
at 20
line big accent MMI 3G+ tests
gap 6
para small text Long text is word-wrapped between the margins (24 px); 30 s stays together.
line small 8A929E     indented: the text is the rest of the line
text 560 100 big FF5A50 placed at x,y
```

```sh
pngondemand example.layout example.png
printf 'bg 004000\ntext 10 10 big ffffff hello\n' | pngondemand - - > hello.png
```

## Source

| File | |
|---|---|
| `main.c` | command line, `-h` help |
| `layout.c`, `layout.h` | the layout language: parse + draw onto a canvas |

The PNG encoding is `img_png_write_argb()` in
[`src/common/img.c`](../common/img.c), over the vendored
[stb_image_write](https://github.com/nothings/stb) v1.16 (commit `1ee679c`),
Sean Barrett, public domain / MIT (`src/common/stb_image_write.h`, unchanged,
licence at the end of the file). It has its own zlib compressor, as the SDK
has neither zlib nor libpng.

Text drawing and fonts are shared with the apps (`src/common/text.c`,
`build/gen/font_*.h` generated by `sdk/mkfont.py`).

Build and test (from the directory with the Makefile):

```sh
make build/pngondemand    # for the car (SH4)
make test                 # tests/test_layout.c, tests/test_png.c + check_png.py
```
